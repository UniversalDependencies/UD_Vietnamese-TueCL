# Summary

This treebank includes a set of sentences from [OPUS](https://opus.nlpl.eu/),
sourced from subtitles, talks, and educational videos.


# Introduction

Along with Khmer and Mon, Vietnamese has a longstanding recorded history in the Austro-Asiatic language family. More than two-thirds of the Austro-Asiatic languages alone are Vietnamese speakers. Plus, only Vietnamese and Khmer have official status as modern national languages. Despite 85 million speakers of Vietnamese, there is only one existing UD treebank for this language so far which is created through a conversion, connoting that Vietnamese is not high-resource.
